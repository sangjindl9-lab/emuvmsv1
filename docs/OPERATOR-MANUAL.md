# EUMBMS 운영자 매뉴얼

대상: 현장 운영자·관제 요원·관리자
버전: EUMBMS 2.0.0

---

## 1. 로그인과 권한

1. 브라우저에서 `https://<서버주소>/login` 접속
2. 이메일·비밀번호 입력
3. 상단에 역할(SUPER_ADMIN/ADMIN/OPERATOR/APPROVER/VIEWER)이 표시됩니다.

| 역할 | 주요 권한 |
|---|---|
| 최고관리자 | 전체 설정·사용자·라이선스·감사로그 |
| 관리자 | 장치·프로토콜·태그·사업장 관리, 제어 요청 |
| 운전원 | 관제, 제어 요청, 검침, 알람 조치 |
| 승인자 | 제어 승인·실행, 알람 조치 |
| 조회자 | 관제·보고서 조회만 |

**중요:** 원격제어 요청자와 승인자는 반드시 달라야 하며, 승인 2명이 필요합니다.

---

## 2. 초기 설정 순서

1. **사업장 관리** → 사업장 등록 (코드, 이름, 계약전력)
2. **건물·설비 관리** → 건물 등록 → 세대(호실) 등록
3. **통신변환기 관리** → 게이트웨이/변환기 등록, 토큰 보관
4. **프로토콜 센터** → 장치 프로토콜 준비
   - 표준 Modbus 장비: ① 기존 프로토콜 선택 → 연결 시험
   - 매뉴얼만 있는 장비: ② 매뉴얼 업로드 → 분석 → 승인
   - 제조사 전용 프레임: ③ 사용자 정의 프레임 → 실제 시험
5. **PLC/RTU 관리** → 장치 등록 → 연결 시험 → 즉시 수집
6. **태그·레지스터 관리** → 주소·형식·배율 입력, 표준 태그 연결
7. **전력 통합 관제 / 단선결선도** → 설비 자산 등록 및 도면 구성
8. **원격검침 / 전기요금** → 계량기 등록, 요금표 등록·적용
9. **알람·장애관리** → 알람 규칙 확인
10. **사용자·권한관리** → 운영 계정 생성

## 3. 장치 등록과 통신 확인

### 3.1 장치 등록
- 장치명, 구분(PLC/RTU/계량기/보호계전기 등), 프로토콜, IP/포트, Slave ID 입력
- 폴링 주기(기본 1000ms), 타임아웃(1000ms), 재시도(2회)
- “표준 태그 템플릿 자동 생성”을 켜면 15개 표준 태그가 생성됩니다. **주소는 임시값이므로 반드시 장비 매뉴얼에 맞게 수정하세요.**

### 3.2 연결 시험
- 장치 목록의 **시험** 버튼 → 실제 TCP 소켓으로 Holding[0]을 읽습니다.
- 실패 시 확인: IP/포트, Slave ID, 방화벽, 장비의 Modbus TCP 활성화, 게이트웨이 모드.

### 3.3 즉시 수집
- **수집** 버튼 → 태그를 읽어 현재값·시계열을 저장하고 알람을 평가합니다.
- 품질: `GOOD`(정상), `UNCERTAIN`(일부 오류), `BAD`(응답 없음/예외), `STALE`(3회 주기 이상 미갱신).

### 3.4 CSV 대량 등록
- 장치: **CSV 내보내기**로 형식을 확인한 뒤 **import**(`devices/import`) 사용
- 태그: 태그 화면 하단의 CSV 입력란에 붙여넣고 **CSV 등록 실행**

## 4. 프로토콜 센터

### 방식 ① 기존 프로토콜
제조사 → 모델 → 프로토콜 → IP/포트/Slave ID → **연결 시험** → **프로파일 저장**.
프로파일은 PLC/RTU 관리에서 장치로 등록할 수 있습니다.

### 방식 ② 매뉴얼 업로드
1. PDF/DOCX/XLSX/CSV/JSON/XML/TXT/ZIP 업로드
2. 자동 분석 결과 확인: 제조사·모델·프로토콜·레지스터 수·신뢰도·경고
3. **검토 대기 프로파일**에서 상세 확인 → 승인 또는 반려
4. 승인 후 **장치로 등록** (`instantiate`) → 태그 자동 생성

주의:
- 스캔 이미지 PDF는 OCR을 지원하지 않습니다.
- 제조사 전용 바이너리 프로토콜은 표준 드라이버로 통신할 수 없으며 별도 드라이버 개발·검증이 필요합니다.
- 자동 분석은 초안이며, 승인 전에는 수집에 사용되지 않습니다.

### 방식 ③ 사용자 정의 프레임
- Header/Length/FC/Address/Count/Payload/CRC 등을 JSON으로 정의
- **요청 미리보기**로 HEX 확인 → **실제 TCP 송수신 시험**
- 성공한 프레임은 드라이버 버전으로 등록하고, 운영 적용 전 시험 검증을 남기세요.
- 변환식은 `raw * 0.1` 같은 제한된 수식만 사용할 수 있습니다(임의 스크립트 불가).

### 호환성 검증표
- `문서 확인`: 공개 문서만 확인
- `드라이버 개발 중`: 구현 중
- `시뮬레이터 검증`: 실제 소켓 시뮬레이터로 통신 확인, **실장비 미검증**
- `실장비 검증`: 현장 장비 통신 증빙 있음
- `부분 지원`, `미지원`

현재 빌드에서 `실장비 검증` 항목은 없습니다.

## 5. 전력 관제와 단선결선도

### 5.1 관제 화면
- 5초 주기로 태그 현재값·품질 표시
- 설비 상태(정상/경고/트립/통신불량)
- **지금 수집 실행**으로 즉시 갱신

### 5.2 단선결선도 편집
1. **단선결선도** → 새 도면 생성
2. 팔레트에서 심벌 추가 (차단기·변압기·발전기·모선·계량기·UPS·태양광·ESS·EV·부하·텍스트·선로)
3. 드래그로 이동, 클릭 후 오른쪽 패널에서 위치·크기·표시명 수정
4. 전력설비 자산 연결 → 차단기 상태 색상(투입 초록/개방 회색/트립 빨강) 자동 표시
5. 계측 태그 연결 → 실시간 값 표시
6. **저장** → 버전 증가

## 6. 원격제어 절차 (중요)

1. **원격제어** 화면에서 설비 선택 (원격 허용·제어 준비 완료 상태 확인)
2. 명령 선택(OPEN/CLOSE/START/STOP 등) + 사유 입력 → **제어 요청**
3. 다른 승인자 계정으로 로그인 → **승인** (2명 필요)
4. 승인 완료 후 **실행**
5. 결과 확인
   - `FEEDBACK_OK`: 최종 상태 반영
   - `UNCERTAIN`: 피드백 미확인 → **현장 확인 필요**, 자동 재전송 없음
   - `REJECTED`: 인터록/Local/트립 등으로 차단

운영 원칙:
- 요청자 본인은 승인할 수 없습니다.
- 현장 스위치가 LOCAL이면 원격 명령이 전송되지 않습니다.
- 인터록 조건이 충족되지 않으면 차단되고 알람이 발생합니다.
- 통신 장애 시 무조건 재전송하지 않습니다. 현장 확인 후 새 요청을 만드세요.
- 모든 단계는 감사로그에 기록됩니다.

---

## 7. 원격검침

1. 계량기를 장치로 등록 (`deviceType=METER`) + `ENERGY_IMPORT` 표준 태그
2. **원격검침** 화면에서 월 선택
3. **지금 검침** → 누적값을 읽어 검침 저장 (감소 시 롤오버 보정 자동 기록)
4. 누락 세대 확인 → 수동 검침 등록
5. CSV/인쇄용 보고서 내보내기

원본 검침과 보정 데이터는 분리 보관됩니다.

---

## 8. 전기요금·에너지 분석

- **전기요금 관리**에서 요금표(JSON) 등록 → **적용**
- 계산기로 월 사용량·피크·계약전력·역률 입력 → 기본/전력량/수요/역률/부가세/기후·연료비 확인
- **에너지 분석**에서 월별 사용량, 전년 대비, 이상 사용량, 탄소배출 추정 확인

주의: 요금은 설정한 요금표 기반 추정치이며 실제 고지서와 다를 수 있습니다.

---

## 9. 알람·장애 대응

1. **알람·장애관리**에서 활성 알람 확인
2. **확인**(ACK) → 담당자 배정
3. 현장 조치 후 **복구** + 조치 내용 기록
4. 반복 알람은 규칙 임계값·노이즈 여부 검토
5. 월간 보고서 CSV 내보내기

알람 통보는 현재 인앱만 동작합니다(이메일/문자/푸시 미연동).

---

## 10. 사용자·라이선스

- 사용자 추가 시 역할 선택. 비밀번호는 8자 이상.
- 라이선스: 에디션·최대 사업장/장치/태그·만료일. 폐기 시 신규 등록 제한 정책은 운영 규칙에 따릅니다.

## 11. 백업·복구

```bash
# 백업 (PostgreSQL)
sh scripts/backup.sh /backup/eumbms-2026-11-22.dump

# 복구
sh scripts/restore.sh /backup/eumbms-2026-11-22.dump
```

권장: 일 1회 자동 백업, 30일 보관, 월 1회 복구 훈련.

## 12. 장애 대응 빠른 점검

| 증상 | 확인 |
|---|---|
| 모든 장치 BAD | 서버↔게이트웨이 연결, 게이트웨이 상태 ONLINE, 방화벽 |
| 특정 장치 BAD | IP/포트, Slave ID, 장비 전원, 케이블, 시리얼 설정 |
| 값이 이상함 | 태그 주소, 데이터 형식, 바이트/워드 순서, 배율·오프셋 |
| 제어 실행 불가 | 승인 2명 여부, Local/Remote, 인터록, 설비 트립, 제어 태그 매핑 |
| 피드백 UNCERTAIN | 피드백 태그 설정, 현장 실제 상태, 통신 지연 |
| 검침 누락 | 계량기 태그 값, 수집 주기, 수동 검침 |
| 로그인 불가 | 계정 상태, 비밀번호, 서버 시간, 쿠키 차단 |
